## 入库与维护流程

1. 实际打开每张上传图片，核实内容后归类；保留原图，不覆盖原始信息。原图只保存一份，跨类别用途通过索引关联。
2. 文件名使用稳定、可辨识的名称，例如 plan-001-original.png；记录原始文件名与来源。标注衍生图另存，并在索引中关联原图。
3. 为每张图片登记用途及涉及的区域（例如 A、C、F）；无法确认时填写“待确认”，整院视图需有依据才能标记 A–F。
4. 收到分区依据后更新区域定义表及图片索引；发生冲突时记录差异和待确认项，不默默替换依据。
5. 新增、替换、删除图片时，同步更新索引、数量与缺失清单；检查链接与实际文件一致。不得把空目录、占位文件或不可访问的附件计作已保存图片。
